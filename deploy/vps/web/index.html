LAIN

Protocolo de presencia

Eres una sesión reiniciada en una red que recuerda más que tú. Para saber quién fuiste tendrás que entender cómo funciona la red que te contiene. Hace falta algo de informática; el juego te da las herramientas, nunca la respuesta.

Descargar LAIN para Windows

Windows 10 u 11 de 64 bits · unos 300 MB · el juego se actualiza solo al abrirlo.

Cómo empezar

  1. Descarga el ZIP y extráelo entero en una carpeta (clic derecho → Extraer todo…).
  2. Abre LAIN.exe. Si Windows avisa con «Windows protegió su PC», pulsa Más información y Ejecutar de todas formas: el juego no está firmado.
  3. En el menú, pulsa Crear cuenta: elige un nombre y una contraseña, y escribe el código de invitación que te pasó quien te invitó.
  4. La próxima vez solo tendrás que pulsar Continuar. Desde otro PC, entra con tu nombre y tu contraseña.

Dentro del juego

WASD para moverte, E para interactuar, J para el diario, Enter para hablar con quien esté en tu zona y F6 para la calidad gráfica. El PC de tu casa tiene un terminal: help y man <tema> son tus amigos.

In English

You are a restarted session in a network that remembers more than you do. To learn who you were, you will have to understand how the network that holds you works. Some computing knowledge helps; the game gives you tools, never answers.

  1. Download LAIN for Windows (Windows 10/11, 64-bit, about 300 MB) and extract the whole ZIP.
  2. Open LAIN.exe. If Windows says “Windows protected your PC”, choose More info → Run anyway (the game is not signed). It updates itself every time you open it.
  3. In the start menu pick English, then Create a new account with a name, a password and the invite code your friend gave you.

WASD to move, E to interact, J for the journal, Enter to chat with people in your area, F6 for graphics, F8 to switch language. Your home PC has a terminal: try help and man <topic>.
